# SpendWise – Personal Expense Tracker

SpendWise is a Python-based command-line application that helps users record expenses, organize spending by category, and monitor their budget.

## Features

- Add expenses with dates, categories, amounts, and tags
- View all recorded expenses
- Calculate total spending
- Display spending summaries by category
- Search expenses by category
- Monitor budget status
- Store expense records using JSON

## Technologies Used

- Python
- JSON
- Regular Expressions
- Object-Oriented Programming (OOP)

## How to Run

1. Install Python 3.10 or newer.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

   `python main.py`

5. Follow the menu options displayed in the terminal.

## Project Structure

- `main.py` – Main menu and application logic
- `models.py` – Expense and ExpenseTracker classes
- `storage.py` – Saving and loading expenses using JSON
- `utils.py` – Date validation, tag parsing, and expense ID generation
